# Dei BioPharma ERP System

An enterprise biotechnology operations and enterprise resource planning (ERP) platform built for **Dei BioPharma Ltd.** (Matugga GMP Manufacturing Facility, Uganda).

---

## 🚀 Key Modules

- **Dashboard**: Real-time operations overview, weekly output performance trend chart, top lead scientists, and live batch activity feed.
- **Finance**: Enterprise ledger, gross revenue, manufacturing OPEX, liquidity reserves, and authorization workflows.
- **HR**: Personnel management, researcher directories, shifts, and payroll processing.
- **Procurement**: Purchase orders, lipid nanoparticles/materials intake, and vendor management.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Vanilla CSS Design Tokens
- **Routing**: React Router v7 (with exact active route indicators)
- **Icons**: Lucide React
- **State & Data**: TanStack Query + Zustand

---

## 🎨 Brand Identity

- **Primary Crimson**: `#C8102E` (Active state indicators, primary CTAs, critical notices)
- **Biotech Forest Green**: `#143D1D` (Emblem, GMP certification, success states)
- **Canvas & Surface**: Crisp pure white (`#FFFFFF`) cards on soft slate canvas (`#F8FAFC`)

## 🏁 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

Architecture Reference

Dei BioPharma — Unified HR & IAM Data Architecture

An enterprise multi-facility architecture integrating Organizational Units (Matugga, Kakiika, Nakaseke, Corporate HQ), Access Control (IAM), Dynamic Schema-Driven Intake, and 21 CFR Part 11 Audit Trails.

🤝 Architecture Evolution & Collaborative Refinements

Design Evolution
📋 Team Baseline Draft
  • 1. Direct User-Employee FK: users.employee_id established basic linking between login credentials and staff records.
  • 2. Flat Role Definitions: Standard role table covered single-facility permission assignments.
  • 3. Static Bio-Data Columns: Captured initial paper registration fields as fixed SQL columns.
  • 4. Core Payroll Elements: Established baseline salary and basic statutory deduction fields.
🚀 Enterprise Multi-Facility Enhancements
  • 1. Decoupled IAM & HR: employees.user_id (nullable) allows external auditors & IT admins to have system accounts without requiring HR contracts.
  • 2. Facility-Scoped RBAC: Added organization_unit_id to user_role_assignments, enabling cross-facility roles with a single login.
  • 3. Dynamic Schema Engine: Integrated form_schemas and custom_fields JSONB, allowing new fields (e.g. Blood Group, RFID) without DB migrations.
  • 4. 21 CFR Part 11 Audit Trail: Added immutable audit_logs entity tracking record changes, timestamps, and IP addresses for WHO/FDA compliance.

2. Data Mapping & Architecture Breakdown

Relational & JSONB Storage
Functional Layer Database Table Relationship Type Architecture Rationale
Corporate Structure organizations ➔ organization_units 1 : N Allows Dei Group holding to operate multiple legal entities and separate facility cost centers.
Identity & IAM users ➔ user_role_assignments 1 : N (Facility Scoped) Enables a single login with different clearance tiers across Matugga (Tier 1 GMP), Kakiika (Tier 2 GCP), and Nakaseke (Tier 3 GAP).
Core Personnel employees Central Entity Decoupled from users. Stores legal labor contract, NIN, and home payroll facility.
Family & Dependents employee_dependents 1 : N (SQL Rows) Allows unlimited children and spouses per employee for healthcare coverage.
Dynamic Intake Forms form_schemas ➔ employees.custom_fields JSONB Extensible Allows HR to add new questions (Blood Group, Biometric RFID, Health Insurance) without database schema migrations.
GMP Compliance employee_certifications 1 : N (Tracked) Tracks license numbers, issuing bodies (WHO, NDA), and automated expiry alerts for 21 CFR compliance.
21 CFR Part 11 Audits audit_logs Immutable Log Meets international pharmaceutical regulatory requirements by logging who modified any record, when, and from which IP.
